SmartSort User Guide

1. Select Target Folder — Click Browse Folder to choose the directory you wish to organize.

2. Scan Directory — Preview storage size breakdown and inspect file categories before performing any move.

3. Dry Run — Test rule execution safely without moving files.

4. Organize Files — Automatically sort documents, photos (sorted by EXIF date), executables, and media into structured subfolders.

5. Undo & History — Revert file movements anytime using SQLite transaction records.
