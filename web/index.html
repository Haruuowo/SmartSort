🚀 User Quick Start Guide

1
Select Folder

Click ● BROWSE FOLDER to pick your Downloads, Desktop, or clutter folder.

2
Inspect Space

Click ● SCAN STORAGE to view folder sizes or ● TOP FILES for large files.

3
Safe Simulation

Click ● DRY RUN to test where files will move without changing anything.

4
Organize Files

Click ● ORGANIZE to automatically group files into Audio, Documents, Images, etc.

5
Clean Up

Click ● CLEAN EMPTY to detect and prune empty abandoned directories.

6
Undo Anytime

Click ● UNDO LAST or type undo to instantly restore moved files.
